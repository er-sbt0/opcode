# opcode

LeetCode-style programming exercises with AI-generated visuals and animations.

## Purpose

`opcode` pairs programming practice problems with AI-generated visualizations
and animations that illustrate how algorithms and data structures actually
work — turning "solve this problem" into "see this problem."

- **Programming exercises** — LeetCode-style coding challenges.
- **AI visuals / animations** — generated illustrations and step-by-step
  animated walkthroughs of algorithms, data structures, and solutions.
- **Learn by seeing** — visualize execution, state changes, and complexity.

## Goals

- Help learners build intuition for algorithms, not just memorize solutions.
- Automate the creation of clear visual explanations for coding problems.

## Status

Early / scaffolding. This directory currently holds only project intent.
